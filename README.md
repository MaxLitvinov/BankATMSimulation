# Банк з обмеженою кількістю ресурсів (Java Multithreading)

Симуляція банку з обмеженою кількістю банкоматів. Демонструє роботу з потоками в Java: `Runnable`, `Semaphore`, стани потоків, обробку помилок.

## Умова завдання

Банк має 3 банкомати. Клієнти (потоки) приходять до банку та намагаються скористатись банкоматом для зняття готівки. Доступ до банкоматів обмежений за допомогою `Semaphore`. Банк працює обмежену кількість часу — після закриття банкомати недоступні, навіть якщо клієнт вже чекав у черзі.

## Реалізовано

- Потоки створюються через `implements Runnable`
- `Semaphore(3, true)` обмежує одночасний доступ до банкоматів
- Окремий потік `BankSchedule` симулює робочі години банку
- Демонстрація станів потоків: `NEW`, `TIMED_WAITING`, `TERMINATED`
- Обробка `InterruptedException` у кожному потоці
- Вивід у консоль зрозумілою мовою (не для програмістів)

## Структура

```
BankATMSimulation.java
├── class BankATMSimulation   // точка входу, запуск потоків
├── class Bank                 // семафор + стан "відкрито/закрито"
├── class BankSchedule         // потік, що керує робочим часом банку
└── class Client                // потік клієнта, що користується банкоматом
```

## Запуск

```bash
javac BankATMSimulation.java
java BankATMSimulation
```

Потрібна Java 8 або новіша (використовує `java.util.concurrent`).

## Приклад виводу

```
Банк відкрився. Банкоматів: 3
Клієнт 5 прийшов до банку.
Клієнт 5 користується банкоматом...
Клієнт 5 зняв готівку і пішов.
...
>>> Банк зачинився.
Клієнт 9: банк зачинений.
```

## Налаштування

У класі `BankATMSimulation` можна змінити:

| Параметр      | Опис                                  |
|---------------|----------------------------------------|
| `ATM_COUNT`   | кількість банкоматів                  |
| `WORK_SECONDS`| тривалість робочого дня в симуляції   |
| `clients.length` | кількість клієнтів                 |
